Project owners can add a registered collaborator with `POST /api/v1/projects/:projectId/members`
and `{ "email": "name@example.com", "role": "EDITOR" }`. Email addresses are normalized;
roles are restricted to EDITOR, REVIEWER, CLIENT or VIEWER. This grants access directly,
does not send email, and returns `ACCOUNT_NOT_FOUND` when registration is required.
The existing member-ID endpoints remain available for role changes and removal.
